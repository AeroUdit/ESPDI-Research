ANALYTICAL POWERED-DESCENT GUIDANCE

ESPDI

Analytical Powered-Descent Initiation for Variable-Mass Rocket Landing

Udit Karthik

A deterministic analytical framework for calculating a fuel-efficient translational landing burn without solving a full online trajectory optimization problem.

View Results GitHub Repository Research Paper

ESPDI-T is the primary contribution; ESPDI-A is the analytical extension.

THE RESEARCH QUESTION

Can an analytical ignition-point calculation reproduce the fuel-efficient translational solution of numerical optimal control?

The problem

A powered-landing rocket must convert position and velocity error into a near-zero terminal state while respecting finite thrust and propellant.

Numerical optimal control can solve this problem, but it requires iterative computation.

The ESPDI idea

Initial state→Burn time→Thrust direction→Ignition point→Landing

ESPDI-T replaces trajectory search with a scalar nonlinear solve plus closed-form equations.

MATHEMATICAL FRAMEWORK

ESPDI-T

The primary method solves the drag-free, constant-gravity, variable-mass point-mass problem analytically.

1

Variable mass

Maximum-thrust mass flow:

\[\dot m_p=\frac{T_{\max}}{I_{sp}g_0}\]

and

\[m(t)=m_0-\dot m_p t\]
2

Burn time

The terminal-velocity condition gives one scalar nonlinear equation:

\[I_{sp}g_0\ln\left(\frac{m_0}{m_0-\dot m_p t_b}\right)=\left\|-\mathbf v_0-\mathbf g t_b\right\|\]
3

Thrust direction

\[\hat{\mathbf u}_{ESPDI}=\frac{-\mathbf v_0-\mathbf g t_b}{\left\|-\mathbf v_0-\mathbf g t_b\right\|}\]

This gives the constant inertial thrust direction for the translational solution.

4

Ignition point

\[K=I_{sp}g_0\left[\left(t_b-\frac{m_0}{\dot m_p}\right)\ln\left(\frac{m_0}{m_f}\right)+t_b\right]\]
\[\mathbf r_I=\mathbf r_L-\mathbf v_0t_b-K\hat{\mathbf u}_{ESPDI}-\frac12\mathbf g t_b^2\]
CORE IDEA

The full translational decision reduces to a scalar burn-time solve, a closed-form thrust direction, and a closed-form ignition-point calculation. No online vector-valued trajectory optimization is required.

ANALYTICAL EXTENSION

ESPDI-A

ESPDI-A adds a terminal thrust-direction requirement while retaining a deterministic low-dimensional construction.

Quadratic acceleration profile

\[\mathbf a(\tau)=\mathbf c_0+\mathbf c_1\tau+\mathbf c_2\tau^2,\qquad \tau=\frac{t}{t_f}\]

The coefficients are fixed analytically by the terminal boundary conditions.

Terminal thrust direction

\[\mathbf a_f=\mathbf g+\frac{T_f}{m_f}\hat{\mathbf b}_{3,f}\]

The resulting thrust profile is then checked against maximum thrust and dry-mass feasibility.

INDEPENDENT VALIDATION

Is the optimizer actually independent?

This is a separate validation experiment. The optimizer is tested from non-ESPDI initial thrust histories and multiple mesh sizes.

Same-seed control

The optimizer is initialized with the ESPDI-T solution and must reproduce the same feasible trajectory.

\[J_{optimizer}\approx J_{ESPDI}\]

Independent rediscovery

Non-ESPDI thrust histories are used as initial guesses. The best feasible numerical solution is then compared with ESPDI-T.

\[\left|\frac{J_{independent}-J_{ESPDI}}{J_{ESPDI}}\right|\rightarrow 0\]
